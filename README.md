# Runner Gallery

A gallery of custom runners for [RunCat Neo](https://runcat-dev.github.io/RunCatNeo/). Browse, download, and import your favorites. Community contributions are welcome.

> [!CAUTION]
>
> - We do not accept issues or pull requests in languages other than English.
> - Issues that do not follow the Issue Template will be closed without question.

## Gallery

Browse and download runners at <https://runcat-dev.github.io/RunnerGallery/>.

Want to add your own runner? See [CONTRIBUTING.md](CONTRIBUTING.md) for the requirements and steps.
